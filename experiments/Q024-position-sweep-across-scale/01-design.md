# Q024-position-sweep-across-scale / Movement 2 — Design

**Status:** NOT YET EXECUTED.
**Location:** reuses `Q023-scale-cost-reentrant-callback/artifacts/q023-spike/` verbatim — the same
built `.exe`, same `FSharp.Compiler.Service 43.9.101` pin, same project shape. No new source is
written for this quartet; only new invocations of the existing binary with different `(N, editIdx)`
argument pairs. Run logs saved under this quartet's own `artifacts/` folder.

## Sweep grid

For each `N` in `{10, 50, 150, 300}` (Q023's own four values, for direct comparability), five edit
positions at approximately 0%, 25%, 50%, 75%, and 100% (last file, index N-1) of the file list:

| N | positions (editIdx) |
|---|---|
| 10 | 0, 2, 4, 6, 9 |
| 50 | 0, 12, 24, 37, 49 |
| 150 | 0, 37, 75, 112, 149 |
| 300 | 0, 75, 150, 225, 299 |

20 runs total: `q023-spike.exe <N> <editIdx>` for each pair, each a fresh process (matching the
correction Q023 itself made — no single-process reuse across configurations).

Each run reports its own cold, 3×repeat, 3×editOne measurements exactly as Q023's harness already
does; only the `editOne` numbers (and the `successors = N - 1 - editIdx` value, computed from the
known grid) are the new data this quartet adds. Cold and repeat numbers from this run are recorded but
not treated as new evidence — they should roughly match Q023's own per-N cold/repeat figures (a
reproduction check in themselves), and any position-independent condition doesn't need re-measuring
except as this cheap byproduct of running the binary anyway.

## Analysis

For each N, fit `editOneMedian ≈ intercept + slope × successors` (linear regression, 5 points per N).
Compare the four fitted slopes and intercepts across N:

- Slopes within roughly the same order of magnitude across N, and each N's fit visually tight →
  supports the model generalizing (SHIP per Movement 1's threshold).
- A slope that itself grows or shrinks systematically with N, or a fit that degrades noticeably at
  larger N → the model needs an N-dependent correction (REVISE, with the correction characterized as
  precisely as the 5-point-per-N data allows).

Also sanity-check the two endpoints per N against Q023's own already-published N=300 numbers (idx 0,
150/positionally-adjacent, 299) as a reproduction check — this quartet's N=300/idx=0/150/299 rows
should closely match Q023's addendum numbers, since nothing about the harness or environment has
changed.
